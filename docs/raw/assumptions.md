## 1. RUNBOOK D1–D22 采纳结论

**全部采纳，无修改**。仅补充可执行口径（不改方向）：

## 2. ASSUMED 决策（PRD 未明确，取最小风险默认）

| # | 假设 | 取值 | 理由 | 若不成立的调整 |
|---|---|---|---|---|
| A-01 | 管理员角色来源 | 仅种子管理员；注册一律 EMPLOYEE | 防止提权；无管理端建号要求 | 如需邀请管理员，另加受控接口（P3） |
| A-02 | Confirmed 能否取消 | 员工与管理员均不可；仅 Pending 可取消 | PRD 只允许 Pending 取消；避免已备餐回补 | 若需管理员取消，增加 `Confirmed→Cancelled`+原因+审计 |
| A-03 | Pending 超时时长 | 创建后 30 分钟自动取消，reason=`TIMEOUT` | RUNBOOK D4 要求超时释放但无时长；30 分钟兼顾演示与备餐 | 可配置 `order.pending-timeout-minutes` |
| A-04 | 截单等号语义 | 等于 10:00:00/15:00:00 即关闭 | 避免边界放行导致超时单 | 若业务允许秒级宽限，改为 `<=` |
| A-05 | 未来日期是否受当日截单影响 | 未来日期不受；仅校验该日菜单已发布 | 截单是“当日餐次”规则 | 若需提前 N 天截止，增加 `max_advance_days` |
| A-06 | 截单自动切换后如何处理用户请求 | 200 创建生效餐次订单并返回 `autoSwitched=true`；若生效餐次已有单 → 409+已有单 | 不阻断用户，规则可解释 | 若要求用户二次确认，preview 强制确认后再提交 |
| A-07 | 预算语义 | 存 `budgetMinCents/budgetMaxCents`，仅用 max 判断提示 | PRD 示例为区间 | 如需按餐次分别预算，扩展字段 |
| A-08 | 5 份上限计数 | 订单内所有明细 qty 之和 | PRD 明确“总份数不是品种数” | 无 |
| A-09 | 未登录能否浏览菜单 | 不能；菜单/下单接口均需认证，未登录 401 | PRD 流程为登录后进入菜单；权限矩阵清晰 | 若允许游客浏览，菜单 GET 放开但下单仍需登录 |
| A-10 | 购物车存储 | 前端本地（Zustand+localStorage），服务端只结算校验；下单成功后清空 | 200 人规模、无跨端同步要求 | 若需跨设备，增加服务端购物车表 |
| A-11 | 地址簿 | 下单可保存新地址（≤200），结算可选历史地址 | PRD 要求“历史地址选择或输入新地址” | 无 |
| A-12 | 菜品数量 | 种子 20 道 = 9 道 PRD 菜 + 11 道补充英文菜 | 支撑分页/列表性能与 20 张图；PRD 允许自行补充，并称约 50 道 | 若只用 9 道，分页需 `size=5` 才能演示 |
| A-13 | 图片归属 | 按文件名 `image_01..20` 映射种子菜，存 imageUrl | 20 张图与 20 道菜一一对应，避免裂图 | 可由管理员重传替换 |
| A-14 | AI 真实 Key | 环境变量提供；无 Key 则规则降级 | 面试现场不提供 Key（PRD §5.2） | 无 Key 时 AI 真实模型质量 NOT TESTED |
| A-15 | Redis | 可选；用于热点预占/限流/缓存；不可用自动降级 DB | RUNBOOK §2/§3；PRD 缓存可选 | 若完全不启动 Redis，`REDIS_PREALLOC` 演示改为配置存在+降级证据 |
| A-16 | 管理员订单处理范围 | 仅 Confirm/Complete/Cancel(Pending)，P2 | PRD §1 提及“处理订单”，§4.3 只要求菜品管理 | 若不做，Tier2 功能分不受影响；看板状态以 Pending 为主 |
| A-17 | 低库存/售罄演示 | 种子全部 20~50；演示时管理员改库存到 3/0 后恢复 | 满足 D21 又展示 §5.1 状态 | 若预置售罄菜，违反 D21“全部上架/20~50” |
| A-18 | “View Existing Order” 触发 | 结算页查询有效单；有则按钮替换并跳转 | PRD §4.2 明确 | 无 |
| A-19 | 搜索语义 | 名称+描述大小写不敏感子串；`%/_` 转义 | PRD §3.2；简单可验证 | 若需分词/拼音，另立需求 |
| A-20 | 菜品删除 | 仅上下架/软删除，不物理删除 | 保护历史订单快照与审计 | 无 |
| A-21 | 字段权限 | 密码哈希/Token 永不序列化；管理员订单列表地址脱敏、详情可见；员工仅本人 | D15 字段权限 | 若需更细粒度，增加字段权限表 |
